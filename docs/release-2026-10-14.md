# UZDONATE 0.2.0

Release date: 14 October 2026.

## Design

- Shared UD monogram, ink/azure/cyan palette, launcher icons, favicon, splash and Telegram welcome card.
- Website and Telegram Mini App share the same refreshed storefront, navigation, wallet, sheets and motion rules.
- Flutter uses the same brand mark and a consistent line-icon family, with compact-screen and large-text refinements.
- Admin shell/login and bot descriptions, commands, support and terms follow the same identity.
- Reduced-motion preferences are respected; keyboard focus is restored after web dialogs.

## Validation

- Backend: 246 tests passed against an isolated local PostgreSQL database.
- Storefront: 60 checks passed across desktop, mobile and 320px layouts. Targeted motion, translated dialog, focus and light-theme contrast checks were repeated after final polish.
- Flutter: static analysis clean and 31 tests passed, including 320px / enlarged-text layouts.
- Release APK: version 0.2.0, code 2, Android arm64, signature verified and debug certificate absent.
- Full admin/storefront/backend production build passed. Runtime Docker images now use Node.js 24.

## Deployment notes

The Android build points to the existing HTTPS API at `https://donate-app-5vhs.onrender.com/api/v1`. Contabo remains a private read-only preview until domain/HTTPS and production cutover are configured. No live payment or provider delivery was attempted during design validation.

The optional bot profile update is available through `backend/scripts/telegram-setup.ts --brand-profile`. It validates the deployed welcome card before updating bot settings and uploads the JPEG profile export through the Telegram Bot API. The caller needs the existing bot token and matching public webhook configuration; secrets are not included in the release.
